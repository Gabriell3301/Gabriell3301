# Gabriell

Desenvolvo ferramentas para simplificar tarefas no computador e jogos em Unity. Nos meus projetos, trabalho tanto nas interfaces como na lógica que liga aplicações, dispositivos e dados.

[Portfólio ↗](https://portifolio.gabryft.dev)

## Projetos selecionados

### QuickSetup

Preparo o Windows para diferentes atividades através de **Rituais**: sequências para abrir e fechar aplicações, organizar ações e ajustar o áudio. O projeto inclui também uma aplicação Android em Java para consultar presença na rede local e enviar Wake-on-LAN; a execução remota de Rituais ainda está por implementar.

**C# · .NET MAUI · XAML · Windows APIs · Java · Android**<br>
Em desenvolvimento · Repositório privado

### Soul’s Bell

O jogo 2D que desenvolvi em Unity para a minha Prova de Aptidão Profissional. Trabalhei nas mecânicas de movimento, combate, dash e parry, com a lógica do jogador organizada em estados.

**C# · Unity**<br>
Projeto académico · [Código](https://github.com/Gabriell3301/Soul-s-Bells)

### ChestCount

Um mod cliente para registar e pesquisar baús no Minecraft, ligado a um servidor local com uma interface web para consultar inventários. A sincronização incremental mantém as últimas leituras confirmadas dos baús, com revisões, backups e tratamento de conflitos.

**Java · Fabric · Python · SQLite · HTML · CSS · JavaScript**<br>
Em desenvolvimento · [Mod](https://github.com/Gabriell3301/Mod-ChestCount) · [Servidor e interface web](https://github.com/Gabriell3301/WebSite-ChestCount)
